## Reference ID scheme
`EL-` eligibility gate · `PR-` prioritisation flag · `DD-` due-diligence disclosure · `MC-` merit sub-criterion · `AF-` application form field · `ATT-` attachment · `BR-` budget rule. Each item cites its guideline section (`GL §x.y`) or form section. When a new round is loaded, keep IDs stable where the requirement is unchanged and prefix with round in storage (e.g. `R19:MC-2a`).
